# Tech AI Zone — The Broadsheet of Breakthrough AI & Tech

Autonomous AI journalism web application featuring multi-agent trend discovery, evidence verification, and real-time tech dispatches.

## 🚀 Features
- **Broadsheet Editorial Design:** Vintage typography, responsive layout, dark/light aesthetics.
- **Autonomous Publishing Pipeline:** Powered by Groq AI and multi-key rotating pool.
- **Evidence Verification Desk:** Automated claim extraction, confidence scoring, and fact audits.
- **Integrated Monetization:** Adsterra ad network and verified affiliate integrations.
- **Full SEO Engine:** Auto-generated metadata, JSON-LD schema, dynamic XML sitemaps, and robots.txt.

## 🛠️ Stack
- **Backend:** Node.js, Express
- **Database:** SQLite
- **Views:** EJS, Vanilla CSS, JS

## 📦 Deployment
1. Set environment variables:
   - `GROQ_API_KEYS`
   - `ADMIN_PASSWORD`
   - `GROQ_MODEL`
2. Run `npm install`
3. Run `npm start`
